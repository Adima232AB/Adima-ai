# Landing Page Update

The new landing page from the supplied `adimaai 23.html` is now rendered through `js/landing.js` while preserving the existing auth modal, dashboard, Firebase, API, history and export flow.

External UI dependencies used by the supplied page (Tailwind CDN, Phosphor Icons, Lottie Player) are loaded in `index.html`.

Do not replace `js/auth.js`, `js/app.js`, `js/api.js`, or Firebase config just to change the landing UI.
